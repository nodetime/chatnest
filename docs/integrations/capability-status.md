# ChatNest 与 Porta 能力现状

目标：通用 Agent 自主选择工具与技能，生成可保存、重开的成果；不预设律师或选品业务流程。

## ChatNest

| 能力 | 已落地 | 真实端到端状态 | 下一步 |
|---|---|---|---|
| 对话与模型 | 流式对话、底部输入框、模型选择、停止 | `gpt-6.1-sol` 实际回答成功 | 补长任务、限流与中断场景 |
| 模型后台 | 地址、Key 加密保存、模型目录、测试连接 | 新配置实际参与任务 | 上线密钥轮换与运维审计 |
| Ask | Agent 原生工具，动态生成表单、保存答案、续跑 | 真实模型自主询问预算和数量并使用回答 | 扩展真实任务问题类型覆盖 |
| Todo | Agent 原生工具、进度投影、历史保存 | 自动化回归已覆盖；本轮真实模型未调用，不计实测通过 | 补真实多阶段任务验收 |
| 个人连接器 | 私有连接与 Key、启停、测试、本次任务范围、逐调用审批 | Porta 实际 MCP 审批与执行通过 | 真实供应商账户验收优先 |
| skills | 个人单文件导入、编辑、启停、删除及任务选择 | 真实模型自主加载现有 skill | 资源包、版本升级及分享待补 |
| 文件上传 | 本地私有存储；PDF、Word、Excel 文本读取 | 本轮真实 DOCX 通过；其余已有解析测试，不等于模型实测 | 补真实 PDF/Excel；扫描件 OCR 待做 |
| 通用产物 | 文本、代码、图片、表格；保存、重开、来源与导出 | 本轮来源表格关闭、重开、刷新后重开通过 | 更多产物类型真实任务覆盖 |
| 分享 | 对话分享 | 独立产物、skills 分享未完整闭环 | 个人私有默认，单独补分享权限 |
| 定时任务 | 尚无完整后台调度与通知闭环 | 未验收 | 完成持久调度、暂停、结果通知后再开放 |
| 订阅积分 | 尚无完整订阅、扣费、退款/冲正闭环 | 未验收 | 先采集真实用量，再接结算与支付 |
| 生产运行 | 本地预览、CI、配置安全边界已有 | 本地可用，不等于线上就绪 | 私有对象存储、配额、备份、监控告警 |

## Porta

| 能力 | 已落地 | 真实端到端状态 | 下一步 |
|---|---|---|---|
| REST / HTTP MCP | 共用供应商实现与原始参数/schema | 实际服务与 ChatNest 调用通过 | 按账号逐接口验证 |
| CLI | 复用 MCP 的发现、查看 schema、调用与诊断 | 既有本地合成数据验收；本轮无新增 CLI 实测 | 核对安装版本与当前发布版本 |
| 通用 skills | Codex 与 ChatNest 共用工具发现和调用指引 | ChatNest 真实模型选择 skill 通过 | 保持版本锁与更新校验 |
| 供应商目录 | 多供应商、原生参数与文档入口 | 目录存在不代表账号权限或接口可用 | 优先真实 1688 搜索、详情、店铺/主体字段 |
| 数据真实性 | 本地联调清晰标注合成上游 | 本轮供应商数据仍为模拟，非真实 1688 | 实测字段、费用、限流、失败率和可用性 |

## 优先级

| 优先级 | 工作 | 完成标准 |
|---|---|---|
| P0 | 合入本轮模型网络与证据修复 | CI 全绿，保留本轮真实模型联调证据 |
| P0 | 真实供应商接入验收 | 用实际账号跑搜索/详情，记录字段、价格、限流与来源；不以本地合成数据替代 |
| P1 | 真实模型回归补齐 | PDF/Excel、Todo、拒绝审批、停止与错误恢复逐项实测 |
| P1 | 上线基础保障 | 私有持久存储、用量与成本记录、配额、备份及异常告警 |
| P2 | 订阅积分与定时任务 | 有完整账本与调度状态，不只做入口页面 |
| P2 | 产物与技能分享 | 授权、撤销、脱敏完整；连接和 Key 始终个人私有 |

证据：[本轮真实模型验收](2026-10-27-real-model-verification.md)；[模型配置](model-settings.md)；[Porta 接入边界](porta-hosts.md)。PR #9 已合并；本轮修复另行提交 PR，不把“已提 PR”写成“已上线”。
