## 实际任务与修复

| 阶段 | 观察与处理 |
|---|---|
| 初始任务 | 按上传说明整理短途旅行包；要求未知预算先提问，标记供应商为模拟数据 |
| Agent 决策 | 询问预算与数量 → 自行加载 skill → 自行选择 Porta 搜索 → 用户审批 → 创建来源表格 |
| 首轮暴露的问题 | 深层证据预览省略商品字段，模型诚实说明尚未逐项核对；首份表格有 3 行，不计为筛选成功 |
| 修复 | 预览支持深层字段与有界多行样本，仍保留 2000 字节信封上限；表格工具允许设置既有通用视图 filter，不改原始证据 |
| 正常用户续问 | 要求基于已有结果核对、不超过 50、只取 2 款旅行包、排除收纳包；未直接执行或重放工具 |
| 最终结果 | 模型自行保存 filter 为“旅行包”的新表格，显示 39.80、45.50 两款；18.20 的收纳包不在当前视图 |
| 上游次数 | 整个任务仅一次搜索，续问未重复查供应商 |
| 信息边界 | 模型指出币种字段缺失、数值仅按返回价格比较，未伪造币种或真实商品结论 |
