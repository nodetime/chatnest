### P2 执行中的裁决记录

- **ChatMessage 类型链迁 domain**:ChatTools/CustomUIDataTypes/ChatMessage 从 app/_lib/types.ts 迁 domain/message/types.ts,_lib 侧留转发 shim,UI 引用点零改动;ArtifactKind(text/code/image/sheet)在 domain 内联字面量并与 _artifacts/*/client.tsx 注释互指。
- **纯函数随迁**:convertToUIMessages/getTextFromMessage/generateUUID 迁 domain/message,_lib/utils 转发。
- **isTest/isProduction 收敛**:新建 server/shared/runtime.ts,_lib/constants 转发同一实现。
- **接口层位置**:四层的接口层 = app/ 的 route/proxy/actions(P0 既定决策,不建 server/interfaces)。
- **续流 ID 保持 ai 的 generateId** 不换 uuid 形态(行为等价纪律);stream_ids 登记经 composition.registerResumeStream,平台层不触碰仓储。
- **测试环境开关改用 OPENAI_API_KEY** 而非 PLAYWRIGHT:同进程串行跑套件时 PLAYWRIGHT 布尔在模块加载期求值会泄漏污染后续文件的 isTestEnvironment(实测 porta/documents 套件被污染翻车);API key 读取是每次调用时求值,after 钩子恢复即可。
- **源码断言测试跟随迁移**:private-uploads/mcp-settings-build/porta-errors/document-ingestion 四处对 route.ts 的字符串断言改为指向 send-message.ts/request.ts(意图不变:上传解析先行、路由导出面最小、Porta 错误品牌化、附件工具挂载)。
- **DELETE 错误语义微调**:db 异常原为未捕获 500,现经 ChatbotError 统一映射(轻微改进,已记录)。
