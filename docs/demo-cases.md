# 数知探AI 演示操作手册

演示主线：**提供参照 → 找到候选 → 查看候选图片 → 解释相似点与差异 → 回看原始来源**。面向律师或品牌方发现相似商品线索，判断为辅助初判。

本文件是操作脚本，不维护另一份完成状态；实测结果、版本及遗留只记录在[唯一研发 TODO](superpowers/plans/2026-11-04-core-launch-goal-and-todo.md)。

## 准备

- 用当前演示入口登录。`admin / 123456` 仅适用于开启开发初始化的本机 dev；服务器账户按该环境实际配置，不能假定自动存在。
- 模型使用已配置的 DeepSeek Flash，1688只启用百炼商品查询。账务和支付关闭。
- 提前准备一张清晰、可公开用于演示的参照商品图片；如没有，使用下方文字参照案例。上传图片应展示实际选中的图片，不能只口述“这里有图”。
- 模型及1688调用会产生实际费用。正式演示用少量候选；侧栏回看已保存的会话不需要重新发送消息。不要为反复展示进度重复查询。

## Case 1：材料缺失时先问清楚

新建对话，发送：

> 帮我在1688找跟我这个设计相似的商品，对比哪里像、哪里不同。

此时不上传图片或链接。预期：Agent 用简洁表单询问参照或关键外观，尚不发起依赖这些信息的商品查询。表单只有必要问题；跳过不会被当作已经提供了材料。

在表单填写具体文字参照，例如：

> 奶油白色蘑菇台灯：圆润半球形大灯罩、短粗柱形底座、灯罩明显宽于底座，整体极简，没有花纹。看外形和比例，不要求同品牌。在1688找类似的商品，说明哪里像、哪里不同。

提交后应自动继续，不要求再次发送或点击“运行”。参照充分时不重复询问同一组条件。

## Case 2：找相似与判断是否相似（主案例）

沿 Case 1 继续，或直接发送完整文字参照。预期可见：

1. 简短的任务进度展示实际阶段，查询自动执行。
2. 右侧工作区自动打开对比表，逐行包含商品名称、来源平台、商品链接、商品主图、外观判断、相似点、差异点和未核实信息。Agent读取实际候选图片，再比较造型、比例和局部差异；表中图片可预览，来源可打开，下载为CSV。聊天保留简短结论。
3. 对每个候选说明“较相似 / 部分相似 / 明显不同 / 信息不足”及具体理由，不只说“相关”。
4. 原始商品信息与模型判断分开；未知店铺、主体等不补造。检索排序分不展示成相似百分比。
5. 看不到图片、查询失败或候选不足时直接说明事实，不用虚构三条填满表格。

观察重点：能否指着候选图解释“灯罩形状相似，但底座更细、更高”这样的具体差异。文字检索命中并不等于视觉相似已确认。

## Case 3：上传图片作为参照

新建对话，上传准备好的图片，发送：

> 在1688找与这张图外形相似的商品，比较轮廓、结构比例和明显差异。

预期：先准确理解参照，再查询并查看候选图片。当前若从图片提取关键词后文字检索，必须说明是**文字召回**；这与把上传图片直接传给1688原生图搜是两条不同能力，不将前者包装成后者。

图片模糊或缺局部时，说明局限；仅当缺失确实影响任务时询问，不强制每次填完整配置表。

## Case 4：Agent 自动计算

这是通用能力的短补充展示，不替代主业务案例。发送：

> 这3组数据共有多少个编号，去重后有多少个：[101,102,103]、[102,104]、[104,105]？

预期：Agent自行调用计算工具，返回总数7、去重5。用户不点击运行；代码与原始输出在工具详情里，正文只展示结果。此工具为隔离 JavaScript 计算，不冒充 Python、终端、文件或网络执行能力。

## Case 5：离开后重开

记录主案例结果，再点击“新对话”，从侧栏重开原会话。预期：

- 参照、问题答案、任务进度、商品来源和最终对比保留。
- 不出现旧审批卡要求重新批准，不自动重发消息、重新查询1688或重新执行计算。
- 发送请求被接受后，原文字和附件即从输入框清空，不等整轮生成结束；失败保留或恢复原草稿，已有新草稿时不覆盖。已完成进度不再转圈。
- 想重新看图时可打开已有来源；后续新问题需要重新视觉检查时由 Agent读取图片，不把历史元数据当作本轮已看图。

## 异常展示

不为演示故意反复消耗真实调用。停止、工具报错、私有地址拒绝、无来源图片和超时主要通过受影响回归验收；需要现场展示时优先展示已有失败会话。

停止后保留已有内容，不自动重试。工具失败显示失败，任务未完成的步骤保持未完成；不能出现失败却宣称完成的总结。

## 演示口径

- 当前讲“找到相似商品线索并解释差异”，不讲已认定侵权或完成法律取证。
- BP的14字段Excel、工商主体补查、批量监测及计费不自动成为本次展示能力；只展示当前实际实现和验过的输出格式。CSV不称为XLSX。
- 本机真实模型和真实1688、服务器镜像与实际入口分别记录证据。没有启动或没有验过的链路不算通过。
