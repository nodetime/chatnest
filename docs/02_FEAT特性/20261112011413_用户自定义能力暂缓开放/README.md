# 用户自定义能力暂缓开放

日期：2026-11-12。状态：已实现，定向回归、类型检查和真实浏览器验证通过；最终体验以用户验收为准。

## 目标与范围

当前 SaaS 产品暂不开放用户自行添加或导入 MCP 与 Skill，由平台提供内置能力。保留现有连接、技能页面与内置能力展示，不删除平台配置，不影响对话中已有内置能力的使用。

用户端添加、创建与导入自定义能力的入口统一置灰。入口仍能响应鼠标和键盘点击，点击后仅提示“产品能力还未开放”，不打开配置弹窗、不选择文件，也不提交创建或导入请求。置灰表示能力尚未开放，不使用会完全阻断点击提示的原生禁用按钮。

## 实现边界

沿用项目现有按钮和消息提示方式，统一关闭用户新增、导入入口；保留平台内置列表和既有只读详情。只处理能力开放范围，不修改模型供应商、密钥、数据库结构或平台内置 MCP、Skill 的执行链路。

核对共享页面中的连接空态添加入口、技能列表菜单和详情中的“创建个人副本”，一起关闭，避免同一 UI 内仍存在新增路径。`app/_lib/capability-availability.ts` 统一消息提示；添加入口使用 `aria-disabled` 和灰色样式，保留点击事件。已有个人技能编辑器内的文件导入入口同样置灰。

本次按用户确认实施用户界面入口限制，既有管理 API、平台管理员页面和运行时保持原样，不将 UI 关闭表述为接口权限封禁。已有用户自定义记录不删除或迁移。

## 验收标准

- MCP、Skill 的用户新增与导入入口呈置灰状态，鼠标及键盘触发时显示指定提示。
- 点击后不打开原表单或文件选择器，不发起新增、导入请求。
- 平台内置能力仍可查看，对话中的原有内置能力链路不受影响。
- 执行相关定向回归、类型检查和真实浏览器验证，不运行完整 E2E 或付费供应商调用。
