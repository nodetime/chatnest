## 布局

参考用户提供的 Lessie、Qoder、Codex 截图，采用 Lessie 的信息顺序。空对话首屏集中展示“AI 侵权线索引擎 Agent”、输入框及三条轻量任务示例，去掉“你的 AI 工作台”小字。示例围绕找线索、做比较、整理产物，体现当前法律业务方向；首屏组件与业务文字分离，未来可替换内容而复用布局。

最近产物完整保留，放在首屏下面的完整第二屏。两屏均占满主区域宽度，最小高度桌面为 `100dvh`、手机扣除 52px 顶栏，产物与输入框共用 800px 内容边界。首屏底部“向下查看最近产物”入口将第二屏顶部滚到主区域顶部，即使产物为空也能完整替代首屏，同时支持自然滚动。侧栏继续保留最近对话的时钟图标及折叠区域。

## 正式接入

- `Greeting` 展示居中产品主标题，桌面 30–34px、手机 25px；输入框下复用原型三条任务示例。点击只填入文字并聚焦，不发送、不调用模型、不清除已有附件。
- `ChatShell` 保持同一个 `MultimodalInput` 及稳定组件位置；附件、模型、本次使用、草稿与发送沿用原链路。首屏最小高度桌面为 `100dvh`，手机扣除现有 52px 顶栏，底部入口只滚动当前主区域；高度不足时自然下滑，减少动画偏好关闭平滑滚动。
- `WorkspaceHome` 位于下一屏，使用真实 `/api/library`，默认最多三条，紧凑列表与真实空态统一使用“产物”。“查看全部”通过 `navigate("files")` 进入既有产物视图，沿用身份保护；打开继续使用 `useOpenSavedArtifact` 的未保存、生成中及跨会话保护。
- 已有消息时只显示原消息流与底部输入框；产品标题、任务示例、下滑入口和最近产物不展示。最近对话继续仅在现有侧栏出现，本任务不改其折叠、搜索和分页。
