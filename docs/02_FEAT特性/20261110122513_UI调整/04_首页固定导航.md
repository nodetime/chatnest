# 任务 04：首页固定导航

## 背景与目标

用户要求首页导航在下滑时始终固定，并学习 Lessie 顶部与下滑后的透明变化。本次将原来的普通流内导航提取为独立组件，保留品牌、产品、使用场景、常见问题、登录和工作台入口。

2026-11-11 两次直接访问 `https://lessie.ai/zh` 均被站点自动跳至地区限制页，未将限制页冒充中文首页滚动验收。该页仍加载公共导航，已读取其原始 CSS：固定顶部 16px，初始透明；滚动样式为 75% 白底、4px 背景模糊、低对比边框和轻阴影。

## 实现与决策

`app/_components/landing/landing-navigation.tsx` 封装导航及移动菜单，由首页传入基础路径和登录状态。样式放在 `landing.css`，使用 `position: fixed` 和 CSS 根滚动时间轴：前 80px 滚动内完成从透明到毛玻璃的过渡，回顶恢复透明，无 JavaScript 滚动监听。

桌面保持 1120px 内容上限、68px 高度；手机为 56px 高度、左右各留 16px。正文预留导航空间，锚点偏移统一按导航高度和顶部距离计算，避免跳转标题被遮挡。未支持滚动时间轴及减少动画时使用固定的半透明底色，优先保证导航可读。

```text
顶部：   透明背景 [品牌]             [导航] [工作台]
下滑：   半透明圆角背景 + 模糊 + 细边框，始终固定顶部
正文：   随页面滚动，锚点落在导航下方
```

## 验证

- [PASS] 修改前真实浏览器下滑 600px，旧导航移至视口外；修改后在顶部、中段、底部均保持 top=16px。
- [PASS] 0px 时透明，40px 时中间状态，下滑后白底透明度 0.75、背景模糊 4px；回顶恢复透明。
- [PASS] 桌面与 390px 手机无横向溢出，移动菜单可打开和关闭，锚点标题不被导航遮挡；减少动画时导航仍可读。
- [PASS] 首页 13 项回归、类型和定向代码规范检查通过；首屏、下滑及手机截图已核对。
