# 任务 03：我们的客户怎么说

## 背景与目标

首页定位为“AI侵权线索引擎Agent”。增加客户评价板块，用律师、律所及公司法务的工作场景帮助访客理解产品价值。本任务归入当前 UI 调整 FEAT，已于 2026-11-11 完成原型确认并接入正式首页。

用户否定初版的播放、翻页、计数及状态栏，要求对照 [Lessie 中文首页](https://lessie.ai/zh) 的自然流动效果。已核对真实站点；后续以确认后的原型为准。

## 位置与线框

板块位于产品演示之后、常见问题之前，只有居中标题和全宽卡片带，左右自然裁切。

```text
产品演示

                  我们的客户怎么说

[左侧露出] [评价卡片] [评价卡片] [评价卡片] [右侧露出]
             整排持续、匀速向左流动

常见问题
```

## 卡片与内容

卡片宽 238px、内边距 16px、圆角 24px，桌面间距 24px，手机间距 16px；标题为无衬线字体。正文 14px／22px，最多六行；底部虚线分隔头像、称谓和身份。按用户 2026-11-12 新要求，鼠标进入评价卡片带时暂停流动，移出后从原位置继续；卡片显示浅蓝选中背景及缓慢呼吸的浅蓝边框，无轮播控制栏或副标题。

六条本地虚构评价覆盖商品检索、律所协作、来源核验、品牌排查、诉讼材料和企业交接，使用“某某律师”等占位身份与文字头像，不使用真人肖像或参考站点客户原文。按用户最新要求，正式首页与原型均去掉身份行的“（示例）”后缀。

## 实现与决策

`app/_components/landing/customer-testimonials.tsx` 封装 `CustomerTestimonials` 和内部 `CustomerReviewCard`，由 `landing-page.tsx` 挂载，样式归入 `landing.css`。本地数据直接参与首屏渲染，无需数据库、接口或轮播依赖。

正式首页 CSS 动画由每组 20 秒调整为 40 秒，移动速度减半；通过 `animation-play-state` 暂停与恢复，不重建动画、不重置进度。悬停暂停仅在支持鼠标悬停的设备生效，避免触屏点击后停住。`ResizeObserver` 测量实际组宽与间距，根据视口补齐副本，卸载时断开；循环仅位移一组距离，避免宽屏末尾露空白。副本通过 `aria-hidden` 避免读屏重复；卡片仅含展示内容，移除会阻断副本悬停的 `inert`，保证每张可见卡片均能高亮。减少动画偏好下停止移动与边框呼吸、隐藏副本，保留原生横向阅读。
