# 06：侧栏与最近记录整理

日期：2026-11-12。范围：工作台导航命名、收起态图标、最近对话位置。

## 最终布局

主对话区域只移除“最近对话”，保留“最近产物”，继续展示真实保存的产物，最多三条。最近产物最终位于完整第二屏，首屏与第二屏的布局以 [07：对话首页原型](07_对话首页原型.md) 为准。“最近对话”集中到侧栏，标题前增加时钟图标，右侧箭头控制整个历史列表展开、收起，默认展开。加载、空记录和未登录状态复用同一个折叠标题。

```text
侧栏展开                       主对话区域
  品牌首页链接 / 开合按钮          第一屏：标题、输入框、任务示例
  新建对话                       首屏底部：向下查看最近产物
  对话 / 产物 / 连接 / 技能       第二屏：最近产物，最多三条
  搜索对话
  最近对话 [时钟] [折叠箭头]
    按日期分组的真实历史
```

## 实现与边界

“文件”入口改为“产物”，同步悬停提示、无障碍名称与页面标题；新建操作统一叫“新建对话”，历史记录的默认标题不改。内部导航键仍为 `files`，沿用现有身份校验与回跳。

收起态统一为 40px 点击区、18px 图标，按钮和图标均居中，隐藏文字与账户展开箭头。所有按钮默认透明，悬停使用同一种背景；当前选中项也不常驻填色。尺寸与前景色在工作台自身的 Tailwind 工具层限定，避免与通用侧栏的强制样式冲突。

`BrandHomeLink` 将品牌图标、文字与首页链接封装在一起；品牌和开合按钮分别定位，顶部行与桌面菜单行固定为 40px，图标列固定为 40px。文字单行裁切并淡入淡出，历史区域固定展开宽度，避免侧栏变宽时文字换行和纵向跳动。保留 208px / 64px 侧栏宽度及减少动画偏好。用户已确认本轮效果并授权提交。

`WorkspaceHome` 只负责最近产物，去掉重复的历史请求；`SidebarHistory` 保留原分组、分页、删除与搜索，在本文件复用 `HistoryGroup` 折叠容器。产物打开与未保存保护继续沿用原实现。

## 验证

相关回归共 10 项通过，Biome 检查通过。真实浏览器确认桌面和手机均保留最近产物，主区域没有最近对话；侧栏时钟图标、折叠及重开正常。七个收起态按钮实测均为 40px，图标 18px，无残留文字，默认透明且悬停一致。验收未发送模型请求。截图仅存本地运行目录，不入库。
