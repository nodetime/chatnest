# 任务 02：消息悬浮栏显示完整时间

## 背景与目标

参考用户提供的 Codex 桌面端消息截图，在 ChatNest 既有消息操作栏增加完整日期和时间，帮助用户核对提问与回复的先后顺序。用户消息和 AI 回复统一使用 `yyyy-MM-dd HH:mm`，例如 `2026-11-10 22:29`，不使用“今天”“星期一”等相对描述。

## 实现与取舍

时间位于复制、编辑或反馈按钮左侧，采用现有弱化文字色、小字号和等宽数字。桌面沿用消息悬浮及键盘聚焦显示；触屏沿用原操作栏可见性。操作栏允许换行，避免窄屏横向溢出，不增加按钮或新的浮层。

`MessageTime` 读取 `metadata.createdAt`，使用浏览器本地时区格式化。服务端渲染保留合法时间的 `time` 元素，时间文字在客户端确定，避免服务端和浏览器时区不同造成水合差异。缺失或非法时间不显示，不以当前时间补造历史。

历史消息继续来自数据库创建时间。新用户消息在发送入口补齐发送时间；新 AI 回复通过 SDK 流元数据接收服务端创建时间，持久化复用同一时刻。审批和 Ask 续接延续原消息时间，编辑用户消息保留其原创建时间；重新生成的回复使用新的创建时间。数据库字段和接口路径保持现有契约。

## 验证

消息时间、发送与交互共 27 项定向回归通过，覆盖用户与 AI 操作栏、本地时区转换、缺失和非法时间，以及真实 SDK 客户端新消息时间；类型、代码规范和补丁检查通过。浏览器使用已有真实会话，核对桌面悬浮可见性与 390px 窄屏：两类消息时间均完整显示，无横向溢出。此次 UI 调整没有发起付费模型调用。
