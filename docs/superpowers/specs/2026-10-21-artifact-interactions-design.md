# ChatNest：执行过程与标准产物查看器

## 已确认的方向

用户明确纠正：右侧不是表格工作台，而是正常打开产物的通用查看器；特殊表格能力放在独立的表格产物内。表格复用 `createResultTable` 工具，显示“生成表格产物”，由 Agent 自选调用。用户随后授权自主打磨实施。

## 视觉与交互

- 左侧的签名结构是一个紧凑的“执行过程”披露组，不再每个工具占一条横贯聊天区的设置行。摘要邻近显示真实调用数、当前状态与展开箭头，不捏造任务计划、时长、百分比或结果条数。
- 连续的、只有普通工具调用的 assistant 消息可以在展示层归组；不跨越用户消息、正文、reasoning、来源或产物。混合消息仅将相邻普通工具分组，保持文字与工具原始顺序。原始 SDK 消息、审批 ID、投票/编辑/重试关系不变。
- 展开后用细竖线和状态节点连接工具，名称/查询紧邻，不把每行“已完成”推到最右边。参数和原始结果继续渐进披露。执行中可见当前步骤；新出现的审批、拒绝、失败自动展开；完成后收起。允许用户手动展开/收起，普通重渲染不重置选择。审批不能被已完成摘要掩盖；只读没有审批操作。
- 右侧继续保留浏览器、产物、来源三种内容，产物按 text/code/image/sheet 使用既有 renderer。一个主标题配类型标识，统一展开/关闭；版本和时间作为次级信息，不重复搭多层标题。历史版本只读与版本回退维持。
- 表格明确标注“表格”，不新增后端 kind；筛选、列、导出、来源、备注只在表格内部出现。收敛为一条主工具栏、主体数据、轻量状态栏；备注通过明确入口按需展开，保存始终可达。保留 CAS、只读源数据、CSV 当前视图、JSON 原始快照与来源/原始行详情。
- 不重做后台、模型配置、上传、Agent 执行和 MCP 协议；无新依赖，复用现有 Tailwind/shadcn/AI Elements 与主题。

## 验收

1. 收起/展开、运行/审批/成功/拒绝/失败、手动选择保持；跨消息与混合内容边界测试。
2. 通用文本和表格都能正常打开，类型标识准确，表格控件不泄漏到其他产物。
3. 表格筛选、排序、列、备注、保存、刷新重开、版本、来源与原始行保持有效。
4. 本地 mock 真实 HTTP MCP + Agent 的浏览器验证；桌面/移动、明暗、键盘与无水平页面溢出。mock 仅在 ignored fixtures，不写入产品逻辑。
5. 主仓重跑显式安全单测、类型检查及隔离直接 Next production build；不读取真实密钥或迁移真实数据库。
