# 数知探AI：Lessie 工作空间统一打磨

用户再次确认沿用已批准的 Lessie 方向（见 2026-10-22／23 的设计记录），本轮不是重新选择风格，也不扩建产品能力。

## 参考与边界

- 本轮实际访问 Lessie 官网；应用／公开示例跳转至地区限制页，未改网络、登录权限或发起收费任务。工作台对照使用 2026-10-22／23 实际浏览器留存截图与测量，不宣称本轮重新看到了设置内部。
- 已留存参考：白色画布、#F7F7F7 次级表面、#262A33 正文、14px 基础排版、48–52px 顶栏、40–46px 表格；薄荷色仅用于语义选择。官网营销渐变、联系人数据、匹配分数、外联功能不进入产品。
- 保留数知探AI名称、原始雷达SVG与仓库/加密标识；不改 Agent、MCP 调度、Ask/Todo 工具定义、权限、保存或供应商配置。不新增积分、订阅、定时任务、工作流的假入口。

## 同一套界面

| 区域 | 本轮呈现变化 | 不变的行为 |
|---|---|---|
| 基础与侧栏 | 白主画布、浅中性侧栏、石墨字色；黑主按钮、细边界；208px 导航与更紧凑品牌/新对话区，账户菜单统一 | 入口、折叠、登录/退出与权限保持 |
| 首页 | 收敛至约840px任务入口，标题与输入形成一个中心焦点；最近任务/成果为低装饰的真实内容区域，去大面积灰底与空态虚线框 | 不补假案例或行业模板，不添加自动任务 |
| 聊天/输入 | 52px顶栏、可读正文、有界消息列；用户消息弱灰，底部输入保留自然边框和轻阴影 | 消息独立滚动，输入固定底部，发送/停止/编辑不跳位 |
| 附件/工具/Ask/Todo | 小尺寸文件块、轻量动作行；等待、审批、失败、表单主次统一；必要参数/错误仍可查 | 动态表单、原始记录、逐次审批、回答/停止/续问语义保持 |
| 通用产物 | 52px标题行；标题和表格操作分层，不再争抢一行；表格/文档/代码/图片仍为普通文件视图 | 拖拽/关闭/全屏/切换、未保存保护、来源与CAS保持 |
| 连接/技能/设置 | 紧凑列表、统一页头与对话框；设置导航和内容独立滚动，移动端有界 | 同一套个人管理组件，真实数据/密钥隔离，不暴露平台模型管理 |

正文/次级文字、可点击控件与焦点保持可读对比；深色按语义变量配套，不用浅色硬编码。动效仅140–180ms的淡入/颜色/展开，不漂浮、不弹跳，遵守减少动态效果设置。

完整对照首页、长聊天、附件、工具运行/审批/失败、Ask展开、Todo、表格与普通文件、连接/技能/设置；1440与390宽度、明暗、键盘导航、长标题均检查。正常预览不接入脚本模型；需要控制状态的应用验收只用隔离的127.0.0.1测试主机，明确为UI夹具，不声称新一轮真实模型或真实供应商验收。运行所有显式离线检查及无迁移编译，截图留忽略目录。
