# ChatNest 通用 Agent 工作台视觉细化

## 已批准方向

用户已明确要求直接实施：以 Codex / Manus 式通用 Agent 为产品基础，借鉴 Lessie 的轻盈、扁平、清晰层级，而非冷灰后台。场景由 prompt + MCP + skills 定制；不在 UI 或工具调度中写死律师、知识产权、电商流程。ChatNest 名称保持，Porta 和管理后台保持独立。

参考为 https://lessie.ai/ 与其公开工作台 https://app.lessie.ai/showcase/3VqeeRzSvUHdivLQGdVVCj 。官网淡彩首页不等于产品工作台；工作台为白底、浅灰分区、石墨文字、细分隔和语义状态色。截图仅作为视觉参考，不复制标识、匹配分数或营销承诺。

## 设计

- Chat 路由局部变量：柔和白主表面、浅中性灰侧栏与悬停、深灰文字；不是大面积冷灰，也不加全屏渐变。暗色对应中性炭黑，不修改全局/admin 主题。
- 结构：去掉聊天/工作区外层浮卡、桌面外边距与重复边框；侧栏、对话、通用工作区贴边平整排列。48px 顶部栏对齐。工作区仍可拖拽/键盘调宽、展开和移动端全屏关闭。
- 细节：统一小圆角控件、图标尺寸、悬停与键盘焦点；正常可读字号，不靠缩小文字完成设计。正文和产物为主，执行过程/来源/技术参数降为次级层。
- 空态与输入：保留自然语言入口；简洁的通用任务提示，不加入行业场景模板或虚构能力。输入框保持柔和边框和必要阴影，非多层卡片。上传/停止/编辑保持原行为。
- 工具：保留现有真实 SDK 顺序与分组。完成默认收起，审批/拒绝/失败真实呈现。人能读懂的调用标题与实际 query/name/url 靠近展示；技术原文仍可查看。不可把未知工具承诺为只读或安全。
- 右侧：正常通用产物查看器，文档/代码/图片/表格通过同一标题/类型/操作层展示。仅表格产物有表格专用筛选、列、导出和备注。不可将整个右侧改成业务数据管理台。

## 不变量

不修改 lib/agent/runtime.ts、prompt/tool selection、审批参数、消息持久化或原始证据；不新增强制工作流、模型调用、依赖、数据库迁移、全局 CSS 重置。保留旧版只读、文档编辑/撤销隔离、来源原文、表格不可变快照和 CAS 保存。不得将前端库宣传为已实现持久后台 Agent 或续流。

## 验收

离线单测、类型检查和改动文件格式检查通过；生产构建在隔离副本中直接 next build --webpack（不运行带迁移的 pnpm build）。真实浏览器以隔离 mock 服务验证：上传读取→Agent 自主工具调用→审批→通用产物打开→表格筛选保存→刷新重开；另查文档编辑/版本、失败/拒绝与空态。390/1280/1440 宽度，明暗两套检查无整页横向溢出；拖拽/键盘分隔、移动端返回、可见焦点、原始证据保持。用实际截图审查最终视觉，单测计数不等于用户认可。

## 浏览器视觉复核补充（用户当前页反馈）

用户看到代码产物打开页仍认为布局不好看，要求继续打磨；不是将组件库本身视作设计验收。实际截图暴露同一短代码在左侧300px大预览和右侧重复、右下悬浮竖向编辑条突兀、标题层级挤、导航占比过大。

- 聊天中的产物使用紧凑文件卡/有界短预览，打开右侧时尤其避免大面积重复编辑器；关闭/再次点击能正常打开，文本/代码/图片/表格均可辨识。不对 Agent 输出正文做重写。
- 将现有产物辅助编辑动作整合到自然的标题栏菜单/区域，不再保留突兀右下竖向悬浮条；保留所有原动作和只读/证据表格保护。
- 优化通用标题/类型/更新时间层级和操作间距；侧栏聊天局部宽度约224px，移动端Sheet保持原交互。右侧依旧通用文件查看器，不引入行业工作台。
