## 真实发现的问题与边界

- 历史自然请求曾发生4次召回（20/20/10/10条）、3次图片读取失败及冗余原始表。技能收敛后，同样自然请求已实测一次查询3项、3次看图成功，无冗余原始表；旧记录保留。最新回复仍重复了聊天总结表，已加强通用产物交接提示，但该提示改动尚未真实复验，留到部署后同一次主线验证。
- 历史回复曾出现“疑似同源/疑似同款货源”。技能已改为只判断可观察外形，最新自然请求未重复此措辞；单次成功不等于每次都稳定遵从，旧回复保留原样。
- 报告最初触发未初始化suggestions崩溃，已补空值兜底；随后发现富文本转换丢链接/表格和CDN拒绝携带来源页的图片。已统一Markdown解析并设置图片no-referrer，真实保存报告重开验证通过，无新增模型调用。核心Prompt保持通用，业务报告格式放在唯一Skill；演示请求已移除“不要建文件”等人为约束。
- 当前图片参照链是“视觉理解 → 文字召回 → 候选看图比较”。私有上传图直接转1688原生图搜尚未接通，不作为已交付能力。
- 最新干净主线自主加载技能，但单次成功不证明每次任务都稳定命中。简短任务可直接执行，不强制为展示生成Todo；Todo4/4证据来自另一会话。
- 自动执行支持同步 JavaScript 计算；不是终端、Python、文件或网络执行环境。固定资源保护不是用户累计消费限制。
- 本轮技术参照图来自已返回商品，不冒充原创设计或法律验证样本。相似判断为辅助初判，不输出侵权认定。
