## 服务器真实主线与本轮修正

现有已部署版本真实会话 `66d9a4d7-baf6-482e-b163-317a7713a115`：实际HTTPS登录、上传参照图片、DeepSeek Flash回复、2次1688商品查询及4次候选看图成功，保存产物 `16b4987a-8055-4cec-b2e9-07676be3be56`。这次发现交付格式仍为长Markdown报告，且发送文字/附件直到整轮结束才清空，工具步骤间运行状态不明显，因此不作为本轮完整通过。

本轮本机修正：

- 唯一 Skill 默认交付已有 sheet/CSV 比较表；补查无有效新增即收敛，候选不足也交付已有结果。先整理完整结果，再一次保存完整 CSV；已有表格按本轮全部修改合并保存，保留当前用户备注、图片和来源，不逐格展示过程。
- 通用核心 Prompt 正文统一在 `server/application/ai/core.md`。末两步通用收尾提醒保留原工具协议与既有执行边界；真正工具循环耗尽持久标记失败，客户端恢复草稿。
- 续聊只恢复历史用过、当前仍选中且权限检查通过的技能最新正文；当前正文放到当轮独立技能指令段，历史调用只留元数据，避免长历史中技能正文埋得过早。旧正文/资源不重放，不预加载无关技能，核心MD未改。
- HTTP 接受后清空本轮文字/附件，晚到失败恢复草稿且不覆盖新草稿；步骤之间显示中性处理状态，不伪造模型思考。
- 表格整体生成错误、截断或空结果不覆盖旧版本；保存成功后只发布最终正文。局部修改无变化不新增版本。产物更新后，即使原工作区已关闭，也可打开同一文件。
- 最后 review 发现不同产物自动切换会越过未保存保护，已复用现有保护拦截该产物流，保留当前编辑器和草稿；已保存结果仍可通过产物入口查看。
