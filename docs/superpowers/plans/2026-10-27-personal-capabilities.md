# 个人连接、技能与本次使用

## 已批准的范围

对齐正式原型 146:1197（连接）、148:1770（自定义 MCP）、146:1362（技能）、148:1839（导入）、148:1604（本次使用）。保持个人空间、平台模型网关、Agent 自主调用和现有审批，不加入业务工作流。管理操作只允许已登录正式用户；访客保留已有平台能力。

## 设计决策

- 复用现有 MCP schema、连接发现、网络目的地校验、加密和编辑器。新增按用户隔离的持久配置，AAD 绑定 owner；个人凭据不进入能力摘要、消息、日志、分享或客户端读取结果。
- 个人连接支持测试、保存、编辑、启停、删除、原生工具白名单；平台连接只读。沿用运维方可信目的地配置，用户输入不自动开放任意内网地址。
- skills 支持标准 SKILL.md 文本导入、预览、启停、编辑、删除和内置技能个人副本。不解压归档、不执行脚本、不隐式授权工具；内置资源保留现有受限读取能力，个人单文件技能只读其指令。
- “本次使用”选择可用连接与技能；未选的能力不连接、不提供给模型，空选择有效，内置 Todo／Ask／上传读取／产物工具保留。
- 选择在会话属主范围内持久保存；每个新用户轮次可调整，待审批续跑使用服务端已保存范围，不信任客户端扩大。个人连接变更、停用、删除或凭据替换使旧审批失效；运行中的调用前再次检查。旧任务不自动继承新凭据。
- 不复制现有 Agent/MCP 执行器，不增加 shell runner，不把 skill 内容当运行权限。

## Chunk 1：服务端与隔离测试

1. 先写失败测试：用户 A/B 同标识连接隔离、密文不能跨用户解密、只读投影无 URL/Key、并发保存冲突、技能解析及范围校验。
2. 新增带中文注释的个人配置／会话范围表和 SQL 迁移（表、字段、主外键和约束全部 COMMENT ON）。复用持久层，不改现有 workspace 单例数据。
3. 实现个人管理用例与认证 API；沿用同源写保护、受限读体、原生 MCP schema 与发现。
4. 接入能力摘要、skills 按需加载、发送消息及审批续跑。范围由服务端验证；撤销后旧闭包不继续外发调用。

## Chunk 2：原型界面与交互

1. 复用 shadcn Dialog/Sheet/Input/Switch、既有 MCP 编辑器，新增个人连接页面管理操作。
2. 技能列表、详情与导入预览、编辑、启停、删除；表单错误不丢输入，删除明确确认。
3. 输入框“本次使用”面板选择当前可用连接／技能，区分平台与个人，保存当前任务；运行和待审批期间不偷偷扩大范围。
4. 全部能力摘要只显示名称、用途、状态与原生工具详情；用户不配置平台模型 Key。

## Chunk 3：主仓验收与 PR

- 类型检查、Biome、显式离线白名单；禁止 pnpm build／付费模型与供应商调用。
- 真实本地 Next/Auth/PostgreSQL：两账号 CRUD 隔离、刷新持久化、导入、选择、停用／删除失效。
- 本地模型/MCP 测试夹具：上传→Agent 按所选能力自主调用→审批／Ask→产物保存→重开；明确不是模型/供应商实网验收。
- 截图检查桌面／窄屏／空态／错误；更新 CODEBASE_MAP、task/lesson，主仓重新验证后创建 PR 并附到本任务。本轮请求为 PR，不自动合并。
