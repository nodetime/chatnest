# 运行时交互优化

延续已获认可的通用 Lessie 风格聊天设计，本轮覆盖实时状态。

目标：自然展示运行中、审批、失败与恢复，不使用供应商专属的脚本化 UI。
架构：保留规范 SDK 消息、现有审批传输和 Agent 选择的工具。展示真实状态，不伪造进度。现有通用产物渲染器不变。

- [x] 检查当前运行中/审批/错误/重试路径；修复前添加回归覆盖。
- [x] 低调且可访问的执行中状态；等待审批不使用无限旋转指示器。保留停止、展开控件和原始详情焦点。
- [x] 审批操作待处理保护、本地提交反馈/错误恢复；精确审批 ID 和参数不变。不重复派发审批。
- [x] 失败时区分可读摘要/原始详情，并提供有用恢复。恢复通过普通会话要求 Agent 重新考虑，绝不盲目重放副作用或丢失原失败证据。遵守只读/忙碌/历史保护。
- [x] 主代理用隔离 HTTP 模型+MCP 测试夹具运行实际请求、审批、延迟工具、错误、恢复和通用产物创建；适当时也检查拒绝/停止。仅使用 mock，不产生实际供应商费用。
- [x] 独立代码审查、明确列出的安全串行套件、类型检查/lint、隔离且无迁移的生产构建及主检出目录验证。
- [ ] 审计 PR 差异（包含此前本地已获认可的 UI 提交）。确保 CI 绝不使用部署数据库/密钥：使用隔离可丢弃服务和明确列出的离线测试。创建 PR、附上链接、等待检查并在不绕过保护的前提下合并；验证 main SHA。
