# 个人管理入口登录修复

## 已确认的问题

访客会被自动创建 guest 会话。个人 API 已拒绝 guest，但侧栏与设置直接挂载个人管理面板，仅在面板内放“登录后可以…”链接，导致访客看到不可操作的管理空壳。登录成功固定回首页，也未保留目标面板。

## 本轮范围

- 保留通用 Agent 的访客试用，不更改模型或工具编排。
- 未登录/guest 点击连接、技能立即到正式登录页；不挂载个人列表与编辑器，不显示解释式登录空壳。
- 账户入口直接显示“登录”，不把 guest 会话呈现成个人账户。
- 设置内部的连接、技能同样守卫；会话读取中不显示未登录提示。
- 登录/注册之间保留经过白名单校验的返回目标，成功后进入相应个人面板。跨身份后清理旧视图缓存，仍保留后端属主与类型校验。
- 登录表单使用现有组件，保留现有表单和验证，不引入新身份服务。

## 验证

1. 先写失败回归：访客/未登录入口、登录目标白名单、跨用户视图隔离、面板未授权不挂载。
2. 最小实现并运行定向测试、类型检查、lint、离线白名单。
3. 实际浏览器验证访客点击连接/技能、设置分支、登录与回到目标；不发起模型或供应商调用。
4. 现有用户会话不做测试账号登录；登录测试仅在隔离浏览器上下文中运行。
