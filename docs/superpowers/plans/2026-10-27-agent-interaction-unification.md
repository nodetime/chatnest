# Agent 交互统一实现与验收计划

**目标：** 按已确认的 Codex 式通用 Agent 交互统一对话、Todo、Ask、工具和产物，不建立业务工作流、不伪造并行 Agent。

**架构：** 保持 AI SDK 工具协议及既有审批边界；复用 AI Elements Question/Task/Tool/PromptInput 与现有产物编辑器。只修状态与展示，不新增数据库结构，不更换模型配置。

## 实现清单

- [x] Ask：补提交途中 Stop 的确认检查；请求异常或中止时只读核实答案是否已落库，未确认时保留草稿和幂等重试；中断的未完成问题不继续显示“正在整理”，不伪造答案。
- [x] Todo：真实 updateTodo 快照驱动；进度列表采用任务图标、有界滚动与长标题换行；成功快照不重复堆在对话执行记录。
- [x] 工具：普通执行过程默认收起，用户打开和正在查看详情的选择保留；审批与错误仍显露。原生文档失败/停止与建议工具复用同一套状态组件。
- [x] 产物：消息卡片与既有产物切换器复用同一未保存/生成中保护；同文件重开不清空内容；核对保存、关闭、重开和通用类型。
- [x] 对话：流式、等待回答、审批、停止及长消息下底部输入位置稳定，不新增固定“继续”话术或另一个恢复流程。

## 验证

先补失败用例再实现；完整离线白名单、类型检查和 lint。真实浏览器与本地 PostgreSQL 验证上述交互分支；需要模型/供应商响应的 UI 回归只在独立 33379 端口的显式夹具运行，不冒充真实模型任务。普通 33378 预览保持原模型配置，测试日志/截图/凭据仅保存在忽略目录。
