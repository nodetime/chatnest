# 后台模型配置

## 已确认范围
平台管理员在独立“模型”页面管理一个当前模型服务（OpenAI / 兼容接口），配置 Base URL、独立 API Key、Chat Completions / Responses 协议、可选模型及默认模型；手动获取模型目录和执行小额真实推理测试。普通用户只选择已开放模型。保留部署环境变量作为尚未配置后台时的兼容来源，不修改进程环境，不混用 Anthropic 凭据。

## 实现
- 独立 ModelSettings 加密数据库行；复用现有主密钥、权限、同源校验；独立 AAD 域，CAS 版本冲突保护。
- Key 从不回传。保留旧 Key 必须是同一精确 Base URL；换地址必须明确输入新 Key。保存和测试分离，测试不改变运行配置。
- 管理配置仅接受公开 HTTPS 目的地（本地测试需显式运维开关），DNS 固定到已验证公网 IP，拒绝重定向；有体积和超时上限。
- 每个聊天请求加载独立模型快照；正文、标题、产物子调用复用快照。进行中的请求不受管理员保存影响，新请求即时生效。
- 测试：纯服务/加密/CAS/权限/网络/运行时隔离，UI 操作、真实模型连接与任务。模拟响应仅用于单元测试，不计入真实模型验收。Porta 测试供应商仍明确标记为合成数据。

## 核验记录
- 工作树全量离线测试通过；覆盖真实 SDK 的本地协议模拟、并发 SSE 与工具内模型子调用，非真实服务验收。
- 浏览器验证：后台页面加载、添加/移除模型、空模型拒绝保存、更换地址后旧 Key 不可沿用、连接失败显示原因、恢复已保存配置。
- 当前运行服务 HTTP 核验：匿名管理读取 401、管理员读取 200、跨域写入 403、换地址沿用 Key 400、失败写入未改变版本，公共模型目录不暴露地址/Key。
- 修复审查发现的 204/205 空响应崩溃；非首行默认模型通过公共目录下发给工作台；管理员接口不再进入游客自动登录重定向。
- 尚无确认可用的真实模型配置；未自动迁移环境凭据，未以本地协议模拟作为真实任务验收。
