# .agents/ - 跨工具共享的 agent 资产

Codex 与 Claude 都会消费的操作性资产。真源是根目录 AGENTS.md,本目录存放它引用的共享内容。

## 消费方式

- Codex:原生读根 AGENTS.md,经其中链接到达这里。
- Claude Code:v2.1.277+ 原生读根 AGENTS.md(同机制);旧版本需手动引用。

## 放什么 / 不放什么

| 放 | 不放 |
| --- | --- |
| 工具中立的技能文档(双工具都按它执行) | 与 `docs/` 重复的内容(文档真源在 docs/) |
| 双工具都要执行的操作标准/清单 | Claude 语法专属资产(去 `.claude/`) |
| | 密钥、环境值、任何敏感信息 |

## 槽位

- `skills/`:工具中立技能(结构对齐 SKILL.md 惯例,但不使用 Claude 专属语法)。
- `standards/`:双工具通用的操作标准。当前为空——项目纪律真源在 AGENTS.md 与 docs/,仅在出现"需要双工具都强制执行且无处安放"的标准时才启用。
